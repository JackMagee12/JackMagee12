# Data inputs

The project uses two CSV files supplied with Jack Magee's coursework:

- `customer_retention_training.csv`: 6,000 labeled rows; `Status` is `Current` or `Left`.
- `test_features.csv`: 1,000 unlabeled rows with the same 34 input features.

The downloadable working package contains the supplied files. The proposed GitHub version omits the raw CSVs. Place authorized copies here to rerun the analysis.

The original publisher, collection dates, whether the data is synthetic, and redistribution terms have not been established. No source attribution or data license is inferred from the filenames.

Do not treat generated prediction row numbers as customer identifiers. The prediction file has no true outcomes with which to measure model performance.
